Develops for SymbOS on Amstrad CPC (Z80). Works with:
- SCC C compiler targeting Z80/SymbOS
- RASM assembler
- Screensavers in the symsav-* family
- Network library (N4C-NETTOOLS) for W5100S Ethernet
- SGX image format tools (conv2SGX)

Prefers clean, minimal code following existing screensaver patterns. Projects share a common structure: SCC-compiled .sav, build.sh, add_preview.py.
